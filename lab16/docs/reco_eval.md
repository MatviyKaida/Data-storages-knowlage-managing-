# Результат 2. Офлайн-оцінка рекомендаційної системи

## Часове розбиття без витоку з майбутнього
- **60 користувачів** (48 warm + 12 cold-start), **16 тижнів** (`2026-08-03` – `2026-11-22`).
- **Train:** тижні 1–12 (`401` взаємодій до `2026-10-26`).
- **Test:** тижні 13–16 (`206` взаємодій після `2026-10-26`).
- Статистична оцінка: 1000-кратний користувацький bootstrap (95% ДІ) + 3 ковзні часові фолди.

## Вибір конфігурації
Для основного продакшен-контуру обрано **Hybrid Weighted (`α=0.45`)**: забезпечує статистично значущий приріст **+56.0% nDCG@10** проти Popularity (`0.5660` vs `0.3628`, довірчі інтервали не перетинаються), 100% покриття каталогу та стійкість до неповних зв’язків графа; для сценаріїв онбордингу нових користувачів рекомендовано перемикач на **Hybrid RRF** (`nDCG@10 = 0.6533`).
