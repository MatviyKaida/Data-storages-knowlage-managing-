# Результат 1. Зерно факту, бізнес-питання та зіркова схема

- **Бізнес-процес:** моніторинг тренувальних навантажень та фізіологічного відновлення атлетів.
- **Зерно факту (`fact_training_load`):** 1 рядок = 1 тренувальна сесія одного атлета у конкретну дату (1 200 рядків).
- **6 бізнес-питань:** (1) Розподіл дистанції за ієрархією таксономії; (2) Сумарний TRIMP по тренерах і фазах мікроциклів; (3) Частка перевантажень `ACWR > 1.30` в ударних мікроциклах; (4) Помісячна динаміка дистанції за класами таксономії; (5) Рейтинг атлетів за HSR у кожній тренерській групі; (6) 7-сесійне ковзне середнє ACWR для раннього виявлення зриву адаптації.
- **5 вимірів:** `dim_date` (SCD-0), `dim_athlete` (SCD Type 2: `valid_from`, `valid_to`, `is_current`), `dim_taxonomy` (таксономія ЛР №5 з IRI `http://lnu.edu.ua/sports-km/tax#...`, `tax_domain -> tax_class -> tax_subclass`, SCD Type 1), `dim_sensor` (SCD-1), `dim_microcycle` (SCD-1).
- **Класифікація мір:** адитивні (`total_distance_m`, `hsr_distance_m`, `duration_min`, `trimp_score`), напівадитивні (`readiness_score_pct`, `rmssd_morning_ms`), неадитивні (`acwr_value`, `rpe_score`).
