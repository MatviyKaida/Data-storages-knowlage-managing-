# Результат 1. Схема витягу та інструкція розмітки

## 1. Типи сутностей (6) та типи відношень (6)
- **Сутності (6):** `BIOMARKER` (напр. `rMSSD`, `ACWR`, `КФК`, `LSI`; контрприклад: загальне слово «показник»), `THRESHOLD` (напр. `ACWR > 1.30`, `LSI >= 90%`; контрприклад: номер року `2026`), `DEVICE` (`Polar H10`, `Catapult Vector`, `Biodex`), `PROTOCOL` (`RTP-FIFA-H2`, `WADA`), `INJURY` (`OSICS HM2`, `ACL`, `тендинопатія`), `METHOD` (`тейперинг`, `VBT`, `DSS`, `LHTL`).
- **Відношення (6):** `MEASURED_BY` (`rMSSD -> Polar H10`), `HAS_THRESHOLD` (`LSI -> >= 90%`), `INDICATES_RISK` (`ACWR -> перетренованості`), `TREATED_BY` (`ACL -> RTP-ACL-P1`), `ASSOCIATED_WITH` (`ACWR -> Readiness`), `APPLIED_IN` (`rMSSD -> тейперинг`).

## 2. Інструкція розмітки (6 правил та граничні випадки)
1. Розмічати лише явно висловлені факти без додумування.
2. Кожне відношення повинно мати точний символьний `offset_start..offset_end` і цитату `evidence`.
3. Напрямок ребра фіксований (напр. `BIOMARKER -[:MEASURED_BY]-> DEVICE`, не навпаки).
4. Числові інтервали (`0.80–1.30`, `350–500 Од/л`) виділяти як єдиний `THRESHOLD` разом з одиницею виміру.
5. Заперечення («повний спокій не рекомендується») не розмічати як `TREATED_BY`.
6. При вкладених термінах обирати найповніший іменниковий вираз із подальшою нормалізацією до канонічного ID.

## 3. JSON-схема та правила нормалізації
- Вихід JSONL: `{claim_id, doc_id, split, head, head_type, head_span, relation, tail, tail_type, tail_span, evidence, offset_start, offset_end}`.
- Нормалізація: синоніми та відмінкові форми зводяться до канонічних ID (`КФК / креатинкіназа / CK` → `BIOMARKER:CK`, `HM2 / S76.3 / біцепс стегна` → `INJURY:OSICS_HM2`).

## 4. Пілотна розмітка (5 фрагментів) та 3 уточнення інструкції
1. Уточнено правило 4: виключено номери років (`2026`) та пунктів (`1.`) із класу `THRESHOLD`.
2. Уточнено правило 3: зафіксовано напрямок `INJURY -[:TREATED_BY]-> PROTOCOL` (у пілоті траплялась інверсія).
3. Додано окремий тип `METHOD` для відділення методик (`тейперинг`, `VBT`) від клінічних протоколів (`RTP`).
