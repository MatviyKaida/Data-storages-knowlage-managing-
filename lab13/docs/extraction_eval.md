- **Метод Б (LLM + JSON-схема + evidence + 2 retries):** `P = 0.954`, `R = 0.838`, **`F1 = 0.892`** (+0.111 F1); без цитати: **1.36%** (2 галюцинації до фільтрації); вартість: **$0.0018/док**.

## 2. Класифікація 12 типових помилок
- **Пропуски (6 помилок, перев. Метод А):** невиявлені неявні відношення `INDICATES_RISK`, `ASSOCIATED_WITH` та `APPLIED_IN` при зміні відмінків або перефразуванні.
- **Шумні regex-пороги (2 помилки, Метод А):** хибне виділення шкали `1–10` як клінічного порогу `THRESHOLD`.
- **Інверсія напрямку ребра (2 помилки, Метод Б):** `PROTOCOL -[:TREATED_BY]-> INJURY` замість `INJURY -[:TREATED_BY]-> PROTOCOL`.
- **Вигадані твердження без цитати (2 помилки, Метод Б):** `VO2MAX -[:MEASURED_BY]-> GYMAWARE` (`DOC-14`) та `RIR -[:INDICATES_RISK]-> ACL` (`DOC-19`), які перехоплюються перевіркою `validate_llm_output()`.

## 3. Рекомендація
Рекомендовано **гібридний конвеєр**: Метод А виконує швидкий безкоштовний витяг точних кодів/порогів (`HAS_THRESHOLD`, `MEASURED_BY`), а Метод Б із жорсткою валідацією цитат `evidence` добирає складні семантичні відношення (`INDICATES_RISK`, `TREATED_BY`, `ASSOCIATED_WITH`).
