- **Версія:** `v1.0-baseline` (дата фіксації: `2026-11-17`; очищена `v1.1-cleaned`: `2026-11-24`).
- **Обсяг:** граф Neo4j (120 вузлів / 245 ребер) + корпус RAG (24 документи / 216 фрагментів); експертна вибірка для точності — **36 записів** (≥ 30).
- **8 вимірів якості:** Повнота (91.7% / поріг ≥95%), Узгодженість (93.2% / ≥95%), Точність (88.9% / ≥90%), Актуальність (94.5% / ≥90%), Унікальність (95.8% / ≥98%), Походження (96.4% / 100%), Валідність SHACL/JSON (94.0% / 100%), Доступність RBAC (100% / 100%).

  3. **Автоматичний CI-gate (12 перевірок)** (блокування некоректних діапазонів, дублікатів і пропусків `sensitivity` до деплою).
