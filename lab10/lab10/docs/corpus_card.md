# Картка корпусу (Результат 1 — Domain Knowledge Hub)

- **Предметна область:** Управління спортивними знаннями (Sports Knowledge Management)
- **Обсяг:** **24 документи** (`DOC-01..DOC-24`), **216 фрагментів** (`CH-0001..CH-0216`) у файлі `data/corpus.jsonl`.
- **Метадані кожного фрагмента:** `chunk_id`, `doc_id`, `title`, `section`, `type`, `date`, `sensitivity`, `source_url`, `text`.
- **Мова:** українська з англомовними спортивно-медичними термінами (`rMSSD`, `ACWR`, `HSR`, `OSICS`, `LSI`, `TRIMP`, `WADA`).
- **Очищення від шуму:** видалено **48** шумних елементів (навігаційні хлібні крихти `[NAV: ...]`, колонтитули `© 2026 ... Сторінка X з Y`, повторювані пробіли та зайві порожні рядки).
- **Рівні доступу (`sensitivity`):**
  - `public` — **108 фрагментів** (загальні наукові регламенти, методики періодизації, нутрицевтика, сон);
  - `internal` — **54 фрагменти** (внутрішні тренерські евристики, архітектура Hub, правила DSS, кінематика);
  - `restricted` — **54 фрагменти** (біохімія крові КФК, ізокінетика LSI, коди травм OSICS, протоколи RTP, антидопінг WADA).
- **Джерела та ліцензії:** відкриті наукові консенсуси (BJSM, IOC, FIFA Medical — CC BY / відкритий доступ для освітніх цілей), документація сенсорних платформ (Polar, Catapult, Cosmed, Vicon, GymAware — технічні специфікації), власні формалізовані регламенти ЛНУ ім. Івана Франка (MIT / освітня ліцензія).
- **Відомі прогалини:** корпус не містить юридичних контрактів стадіонів, індивідуальних персональних даних реальних атлетів (знеособлено згідно з GDPR) та вузьких хірургічних протоколів.
